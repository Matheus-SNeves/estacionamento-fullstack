# 🚗 Sistema Web para Gestão de Estacionamento

Aplicação web desenvolvida para otimizar o controle, registro e gerenciamento de estadias de veículos em estacionamentos. O projeto possui foco em usabilidade e na organização prática do fluxo de entrada e saída.

🔗 **[Acessar a aplicação online](https://matheus-sneves.github.io/estacionamentoMatheus-SNeves/estadias/estadias.html)**

## ⚙️ Funcionalidades

* **Registro de Estadias:** Cadastro de entrada de veículos especificando placa, modelo e horário.
* **Controle de Saída:** Gerenciamento do tempo de permanência e cálculo do valor da tarifa.
* **Monitoramento do Pátio:** Listagem clara dos veículos que estão atualmente estacionados.
* **Interface Responsiva:** Layout adaptável para facilitar a visualização em diferentes tamanhos de tela.
